# WebDB Prototype (Frozen Snapshot)

This directory contains the frozen snapshot of the **WebDB Vertical Slice ("Walking Skeleton")** prototype implemented according to [`docs/plans/prototype.md`](../docs/plans/prototype.md).

It has been preserved for historical reference, regression testing, and verification prior to the Phase 1 Storage & Memory Architecture implementation.

## Structure
- `src/`: Frozen prototype engine, compiler, catalog, slotted pages, and storage adapters.
- `tests/`: Frozen prototype test suites.
- `examples/`: Frozen prototype demo.
